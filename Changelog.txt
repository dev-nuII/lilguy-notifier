13. moved the frontend (index.html, sw.js) into this same Vercel project so the game and the API are served from one origin. The GitHub Pages / Vercel split was causing the save-code cookie to be a third-party cookie, which Safari (and increasingly other browsers) block by default -- the cookie never actually got stored, so every request looked cookie-less: notifications failed with "save not found" and every save-triggering request minted a brand-new save code instead of reusing the real one. Same-origin fixes this. Switched the cookie to SameSite=Lax (no longer need SameSite=None for a cross-site cookie) and switched fetch() calls in index.html to relative /api/... paths.
